Как добавить новый материал

Этот сайт — статический. Чтобы добавить новую страницу в каталог, откройте файл index.html в любом редакторе, найдите в самом низу блок const materials = [...] и скопируйте одну строку-объект.

Шаг 1. Положите новую страницу в ту же папку, где лежит index.html.
Шаг 2. Добавьте в массив materials новую запись.
Шаг 3. Сохраните файл, обновите браузер — карточка появится сама.

Показать код, который нужно скопировать

Скопируйте этот блок целиком и вставьте его перед закрывающей скобкой массива:

{ num: "03", tag: "ТЕСТ", title: "Итоговый тест по ТМЦ", desc: "20 вопросов для самопроверки после прохождения курса", url: "test.html" },

Что менять: num — номер, tag — метка, title — название, desc — описание, url — имя файла.
