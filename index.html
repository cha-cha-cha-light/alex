Как добавить новый материал

Этот сайт — статический. Чтобы добавить новую страницу в каталог, откройте файл index.html в любом редакторе (Notepad++, VS Code, Sublime), найдите в самом низу блок const materials = [...] и скопируйте одну строку-объект.

Шаг 1. Положите новую страницу (например, test.html) в ту же папку, где лежит index.html.
Шаг 2. Добавьте в массив materials новую запись.
Шаг 3. Сохраните файл, обновите браузер — карточка появится сама.

Показать код, который нужно скопировать

Скопируйте этот блок целиком и вставьте его перед закрывающей скобкой массива:

// Скопируйте этот блок ↓ и вставьте его перед последней "];" { num: "03", tag: "ТЕСТ", title: "Итоговый тест по ТМЦ", desc: "20 вопросов для самопроверки после прохождения курса", url: "test.html" },

Что менять: num — порядковый номер (01, 02, 03…), tag — короткая метка категории, title — название, desc — описание в одну строку, url — имя файла страницы (без пробелов, латиницей).

Номера идут подряд — если добавили материал посередине, не забудьте сдвинуть номера у следующих карточек (или просто ставьте любые — это визуальная метка, а не строгий порядок).
